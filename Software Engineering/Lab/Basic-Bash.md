# Основы работы в командной строке. Интерпретатор bash
## Шаг 1 — Справка

`man`         - Утилита для чтения мануалов
`whatis`      - Выводит однострочную справку по команде и страницы `man` для дальнейшего чтения
`info`        - Расширенная информация по утилите
`echo`        — Печатает стандартный ввод в стандартный вывод
`id`          — Вывести различные ID пользователя (GID,UID и т.д.)
`whoami`      — вывести имя текущего пользователя
`who`         — вывести именя залогиненных сейчас пользователей
`pwd`		— вывести полный путь до текущей директории
`passwd`	— поменять пароль пользователя
`less`		— почитать данные файла
`cat`		— вывести данные файла в стандартный вывод
`ls`		— перечислить поддиректории (`-l` списком; `-d` только директории)
`cd`		— поменять директорию
`touch`		— Создать файл или поменять его дату создания/изменения
`wc`		— Счётчик слов
`mkdir`		— Создать директорию (-p для нескольких вложенных директорий)
`rmdir`		— Удалить директорию (но только пустую)
`rm`		— Удалить файл (-r рекурсивно)
`cp`		— Копировать файл
`mv`		— Переместить/переименовать файл 
`date`		— Печатает дату с возможностью форматирования через +"..."
`cal`		— печатает календарь
`recode`	— конвертирует текст из одной кодировки в другую. Применяется на месте и может конвертировать LF/CRLF, а также закодировать в Base64 [Источник](https://stackoverflow.com/questions/64860/best-way-to-convert-text-files-between-character-sets)
`iconv`		— конвертирует текст из одной кодировки в другую
## Шаг 2 — Экранирование

Замены:
1. `echo '"a "bc$a" '` — `'` так как двойные кавычки уже есть в строке
2. `echo " a'abc$'c "` — `"` так как одинарные кавычки уже есть в строке
3. `echo "a\b $c\$d "` — `"` проще чем писать `\\` перед каждым мета-символом

`echo 'a"'"b'` — ошибка, так как внутри одинарных кавычек все символы интерпретируются буквально, поэтому чтобы вывести `'a'b'` нужно экранировать всю строку — `"'a'b'"`
## Шаг 3 — Простая команда, код возврата

Команды 
`who --count` — очевидно
`date +"%d %B %Y"` — `%B` выводит полное название месяца, определённое текущей локалью
`cal 1752 > calendar` — перенаправляет вывод `cal 1752` в файл `calendar`
`cat --number-nonblank calendar` — очевидно
`wc --words calendar` — очевидно
## Шаг 4 - Смена кодировок

Командой `iconv -f <исх. кодировка> -t <целевая кодировка> file_koi > <вывод>` меняем кодировки и выводим в соответствующие файлы (по умолчанию `iconv` выводит в стандартный вывод) 

```shell
pecherkin@debian:~/shell_lab1$ ls -lAh
итого 20K
-rw-r--r-- 1 pecherkin pecherkin 2,9K фев  4 08:13 file_koi
-rw-r--r-- 1 pecherkin pecherkin 5,2K фев 10 15:13 file_utf
-rw-r--r-- 1 pecherkin pecherkin 2,9K фев 10 15:12 file_win
-rw-r--r-- 1 pecherkin pecherkin   33 фев 10 14:36 quoting
pecherkin@debian:~/shell_lab1$ 
```

Получаем, что файл в кодировке UTF-8 весит почти вдвое больше файлов в КОИ8 и Win1251, так как использует 2 байта на символ вместо 1
