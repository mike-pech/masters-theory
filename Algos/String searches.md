# Префикс функция

> Задача: Найти наибольший префикс строки равный суффиксу
> Пример: **ab**cab**ab** — наибольший префикс **ab**

![[Pasted image 20251218192153.png]]

Разбор — найти подстроку $a$, найти такую же подстроку $a'$ в конце строки. Обновить наибольшее значение при нахождении

![[Pasted image 20251218192427.png]]

При нахождении одинаковых $a$ и $a'$ следующие $a$ и $a'$ будут отличаться только на $+1$ 

Следовательно сравниваем $k$ и $k+1$

Под индексом $k-1$ находится значение префикс-функции для строки $a$, что равно суффиксу общей строки

![[Pasted image 20251218193610.png]]

![[Pasted image 20251218193723.png]]

> $p[p[i-1]-1] = p[k-1]$ — розовая строка

![[Pasted image 20251218193857.png]]
### Псевдокод

```
if (i == 0) return 0
for (int i = 1; i < n; i++) {
	k = p[i-1]
	while (k > 0 && s[i] != s[k]) {
		k = p[i-1]
	}
	if (s[i] == s[k]) {
		k++
	}
	return k
}
```
### Асимптотика

При цикле асимптотика может казаться O(n), но из-за того, что в `while` мы можем упасть не больше раз, чем мы поднялись, соответственно общая асимптотика O(2n) ≈ O(n)
# Поиск подстроки в строке — KMP

Имея строку $S$ мы проходимся по строке $M$ и ищем $S'$ в строке, постепенно увеличивая границы и проверяя сходство с $S$

Объединяем искомую $S$, и строку $M$ через спецсимвол-разделитель `#` 

Проходимся и увеличиваем $k$, если сходство увеличивается

Если сходство закончилось, не торопимся сбрасывать, а уменьшаем $k$, пока не найдём верное

Далее проходим по массиву длин префиксов и ищем префикс длиной нашего суффикса — это конец искомой подстроки — откатываемся на его его длину назад и находим начало!

![[Pasted image 20251218195726.png]]
### Оптимизация — пересчёт

Вместо пересчёта значения префикс-функции по новой, считаем $k+1$ по предыдущей $k$
Следовательно, для оптимизации памяти мы можем просто забывать все значения, кроме предыдущего и равного по длине подстроки — по памяти O(M+1) ≈ O(M) — так мы сможем работать с большими текстами
### Асимптотика

По времени O(n+m) — проходимся по тексту N и сравниваем с подстрокой M
