> Граф — это множество вершин (узлов, нод) и рёбер, которые соединяют эти вершины. E — множество рёбер, V — множество узлов

 Граф может быть *соединённым*, если все его вершины соединены рёбрами (не обязательно циклично).
- Граф может быть *цикличным*, если из его вершины можно проложить путь к ней же самой.

- Граф может быть *конечным* или *бесконечным*.

- Граф является *простым*, если все его вершины имеют не больше одного ребра и не содержат петель. Если граф содержит петли, то он называется **псевдографом**

- Граф может быть *направленным*, если рёбра имеют направления. Иначе, он *ненаправленный*.

- Граф называется мультиграфом, если множество его рёбер содержит параллелльные рёбра. По аналогии с простым графом, если мультиграф содержит петли, то называется псевдомультиграфом. 

- Граф называется нуль-графом, если множество его рёбер пустое

- Полный граф — это простой связный граф, в котором каждая пара вершин смежна.

Граф G называется изоморфным графу H, если для него существует биекция f из множества вершин графа G в множество вершин графа H, которая при этом сохраняет инцидентность рёбер графа G в графе H и наоборот. В случае с направленными графами также должная сохраняться ориентация рёбер. В случае со взвешенными графами должен сохранятся вес. 

Подграф, т.е. подмножество вершин и рёбер графа является графом.

Теория графов не обладает устоявшейся терминологией. Поэтому в некоторых публикациях могут использоваться термины, отличные от приведенных ниже.

_Вершина (узел, точка)_ (vertex, node, point) графа G есть элемент множества вершин v∈V(G);
- _Ребро (линия)_ (edge, line) графа G есть элемент множества ребер e∈E(G) или e={v1,v2}, где v1∈V(G),v2∈V(G)

- _Элементами_ графа G называются его вершины v∈V(G) и рёбра e∈E(G)графа

- _Порядок_ (order) графа G есть кардинальное число множества вершин n=|V(G)| или, другими словами, количество вершин

- _Размер_ (size) графа G есть кардинальное число множества ребер m=|E(G)|или, другими словами, количество ребер

- Вершина v _инцидентна_ (incident) ребру e, если v∈e; тогда еще говорят, что e есть ребро при v

- _Концевые вершины (концы)_ (endvertices, ends) есть две вершины, инцидентные ребру. Ребро _соединяет_ (joins) свои концевые вершины

- _Соседние (смежные) вершины_ (neighbours, adjacent) есть такие вершины v1 и v2 что {v1,v2}∈E(G) или, другими, словами обе вершины являются концевыми для одного ребра

- _Смежные ребра_ ( adjacent edges) это ребра, инцидентные одной вершине или e1={v,v1} и e2={v,v2} — смежные

- _Степень (валентность) вершины_ (degree, valency) d⁡(v) есть количество инцидентных ей рёбер. В направленных графах разделяют также степень входа и степень выхода (self-explanatory)

- _Изолированной вершиной_ (isolated) называется вершина со степенью d(v)=0, то есть не является концом ни для одного ребра

- _Висячей вершиной (листом)_ (leaf) называется вершина со степенью d(v)=1, то есть которая является концом ровно одного ребра.

## Обходы
### Обход в глубину (Depth-first Search)

Три вида вершин
- Белый — ещё не обработали вершину
- Серый — уже были на этой вершине, но не закончили обработку (есть куда идти)
- Чёрный — вершина обработана (не куда уже идти)

Так мы запускаемся и ходим по смежным вершинам в глубину, на каждом шаге красим вершину в серый и идём на белые вершины. Если из белой вершины больше некуда идти, кроме серой, то мы закрашиваем серые вершины в чёрный — там мы уже были

Таким образом мы возвращаемся в белые вершины и проходим другие белые вершины, пока все вершины не станут чёрными 

Алгоритм реализовывается либо циклом, либо рекурсией

```
dfsInternal(v) {
	v.color = 1
	for (u: G(v)) {
		if (u.color == 0) {
			dfs(u)
		}
	}
	v.color = 2
}

dfs() {
	for(v : V) {
		if (v.color == 0) {
			dfsInternal(v)    // Если нужен счётчик глубины,
		}                     // то добавляем его в функцию — dfsInternal(v, count)
	}
}
```
### Обход в ширину — Breadth-first Search (BFS)

Понадобится очередь на обработку вершин и два класса вершин:
- Белый — не обрабатывали
- Чёрный — в очереди на обработку или уже обработали

1. Достаём вершину из очереди
2. Рассматриваем все смежные ей вершины
3. Добавляем смежные вершины в очередь, красим их в чёрный
4. Повторяем, пока очередь не опустет

```
bfs(v, q) {
	for (u:I(v)) { // Как-то определяем инцидентные вершины (скорее всего v.next)
		if (u.color == 0) {
			q.enqueue(u)
		}
	}
	bfs(q.next(), q)
}
```
