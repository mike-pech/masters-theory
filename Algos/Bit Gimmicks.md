# XOR
## Найти уникальный элемент (или элемент в нечётном кол-ве)

Все элементы множества нужно сделать XOR с 0. Первое чтение элемента 5

```
0 — 0000
5 — 0101
^=
    0101 
```

Далее, при XOR нескольких других чисел

```
	0101
9 — 1001
2 — 0010
6 — 0110
^=  1000 
```

Снова XOR

```
	1000
9 — 1001
2 — 0010
6 — 0110
^=  0101 — Снова 5!
```
