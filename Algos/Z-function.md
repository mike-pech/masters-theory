## Задача

Найти максимальный префикс, который ещё и суффикс — к примеру задача на литкоде 

> Выведите true, если строку можно вывести конкатенацией какой-либо её подстроки, и false в обратном случае

При помощи z-функции можно просто найти для i-го индекса строки значение совпадающих с началом строки символов
## Случаи

### 0 случай

`i > r`  — просто перебираем строку через `while` пока не наткнёмся на различие и увеличиваем значение z-функции
### Тройник случаев (1–3) — `i < r`
### `z[i-l] < r - i + 1`

![[Pasted image 20260113132116.png]]

Красный кусочек голубой подстроки имеет различающиеся с префиксом символы `a` и `b` (в префиксе `c`) — значит дальше мы идти не можем и берём красную подстроку
### `z[i-l] > r - i + 1`

![[Pasted image 20260113132539.png]]

Красные строки, от которых мы итерируем, длинее ранее известных синих строк. Символ `x` красной строки совпал с символом `z` в префиксе, но с `x` не совпал `y` — значит и префикс `z` не совпадёт — берём синюю подстроку, т.к. не можем идти дальше
### `z[i-l] == r - i + 1`

![[Pasted image 20260113132918.png]]

Тут нам неизвестно, можем ли мы пройти дальше, поэтому `z[i]` равна и синей, и красной подстрокам — берём любую и идём перебирать 
## Реализация

Тут на самом деле можно упростить — следите за руками

```c++
class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        int l = 0, r = 0, n = s.size();
        vector<int> z(n);
        for (int i = 1; i < n; i++) {   // z-функция не определена для i=0
            z[i] = min(z[i - l], r - i + 1); // Случай 1,2 — уже ответ; 0 — отрицательное число; 3 — предварительный ответ и надо шагать
            z[i] = max(0, z[i]);    // Если получили отрицательное число, то заменяем его на 0
            while (i + z[i] < n && s[z[i]] == s[i + z[i]])
                z[i]++;    // Простой перебор для случаев 0 и 3
            if (i + z[i] - 1 > r)   // для случаев 0 и 3 обновляем границы
                l = i, r = i + z[i] - 1;
            if (z[i] + i == n && n % (n - z[i]) == 0)
                return true;  // Поняли, что дошли до конца и, если строка нацело делится найденной подстрокой, то её можно воспроизвести — true
        }
        return false;
    }
};
```
