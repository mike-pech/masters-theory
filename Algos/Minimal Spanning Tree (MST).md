# Минимальное остовное дерево
## Определение

Минимальное остовное дерево (minimal spanning tree) — Дерево (ацикличный граф),связывающий все вершины и имеющий минимально возможный вес рёбер
### Лемма о безопасном ребре (key lemma)

Пусть дан граф G с весовой функцией w. Если (S, V/S) — разрез графа G, а её ребро минимального веса, пересекающее этот разрез, то оно входит в какое-то MST графа G

## Алгоритмы
### Алгоритм Прима

Сборка MST через добавление к начальной вершине (и далее к другим вершинам) минимальное ребро до тех пор, пока не охватим все вершины графа, сделав MST

![[Pasted image 20251211194409.png]]
В этом разрезе смотрим из достижимых рёбер одно с минимальным весом — ребро 3–6 с весом 2

> [!INFO] Как найти минимальные рёбра?
> Аналогичный Дейкстре алгоритм, в котором мы рассматриваем ребро с максимальным приоритетом (минимальным ребром из MST до неё). Рассматриваем рёбра, исходящие из неё. И если какою-то ребро можно привязать дешевле, через эту вершину, то обновляем приоритет

![[Pasted image 20251211195142.png]]
Ребро 2 можно было привязать изначально за 8, а потом выяснилось, что можно привязать за 1 — соответственно обновляем приоритет, а затем и выбираем её как наименьшее ребро
#### Реализация

```c++
typedef pair<int, int> pii; // (вес, вершина)

int prim(int n, vector<vector<pii>>& graph) {
    vector<int> visited(n + 1, 0);
    priority_queue<pii, vector<pii>, greater<pii>> pq; // Мин-куча (меньшие веса сверху)
    
    pq.push({0, 1}); // До первой вершины вес 0
    
    int totalWeight = 0;
    int edgesUsed = 0;
    
    while (!pq.empty() && edgesUsed < n) {  // Идём пока очередь не опустеет
										// несвязный граф
										// или пока не соберём n-1 рёбер
        auto [weight, edge] = pq.top();
        pq.pop();
        // Берём наименьшее по весу ребро из min-кучи
        if (visited[edge]) continue;
        // Если не юзали, то добавляем его и прибавляем использованных рёбер
        visited[edge] = 1;
        totalWeight += weight;
        edgesUsed++;
        // Добавляем неиспользованные соседние рёбра
        for (auto& [neighbourWeight, neighbour] : graph[edge]) {
            if (!visited[neighbour]) {
                pq.push({neighbourWeight, neighbour});
            }
        }
    }
    // Возвращаем вес MST
    return totalWeight;
}
```
#### Асимптотика

При реализации через приоритетную очередь сложность по времени $O(E + V\ log\ V)$  — количество рёбер + поиск среди вершин в приоритетной очереди среди всех вершин — оптимально для полносвязного графа! 
### Алгоритм Краскала

Отсортируем рёбра в порядке возрастания весов. Далее идём от большего к меньшему и берём те, которые не образуют цикл — то есть соединяют разные компоненты (группы соединённых вершин)

### Как понять, в одной компоненте ли вершины?
#### Покраска

Простая наивная покраска вершин. Одно число — один цвет — одна компонента — не берём
#### СНМ

Система непересекающихся множеств — множеств, которые представляет главенствующая вершина, а остальные содержат указатели на их представителя — Операции поиска и привязки O(1) — найс

![[Pasted image 20251211201239.png]]
##### Эвристика сжатия путей

При прохождении путей через Find переписываем вершины с их родителей на представителя, чтобы дальнейшие поиски были быстрее

![[Pasted image 20251211201507.png]]
В конце получится вершина с кучей лучей, исходящих из неё в другие вершины

#### Реализация

```c++
struct Edge {
    int u, v;
    long long weight;
    
    bool operator<(const Edge& other) const {
        return weight < other.weight;
    }
};

class DSU {
private:
    vector<int> parent;
    vector<int> rank;
    
public:
    DSU(int n) {
        parent.resize(n + 1);
        rank.resize(n + 1, 0);
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
        }
    }
    // Поиск схож с восстановлением пути через родительские вершины
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    // Объединение через сжатие путей до корня
    bool unite(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
	    
        if (rootX == rootY) return false; // Уже в одном множестве
        // Смотрим у кого меньше ранг и добавляем множество к нему
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
        
        return true;
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int n, m;
    cin >> n >> m;
    
    vector<Edge> edges(m);
    
    for (int i = 0; i < m; i++) {
        cin >> edges[i].u >> edges[i].v >> edges[i].weight;
    }
    
    sort(edges.begin(), edges.end());   // Сортируем рёбра по весу
    
    DSU dsu(n);
    long long totalWeight = 0;
    int edgesUsed = 0;
    // Объединяем рёбра пока они не станут одной компонентой
    for (const Edge& edge : edges) {
        if (dsu.unite(edge.u, edge.v)) {
            totalWeight += edge.weight;
            edgesUsed++;
            if (edgesUsed == n-1) {
                break;  // Или пока не построим MST обойдя n-1 рёбер 
            }
        }
    }
    
    cout << totalWeight << "\n";
    
    return 0;
}
```
#### Асимптотика

При реализации через приоритетную очередь сложность по времени $O(E\ log\ V)$  — (сортировка рёбер, но она не считается + ) количество рёбер на рекурсивный поиск в системе непересекающихся множеств — хорош в общем случае
